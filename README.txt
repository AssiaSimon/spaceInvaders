______________ Projet: 

Ce projet consiste à développer un jeu Space Invaders en Python avec une interface graphique réalisée avec la bibliothèque Tkinter.

Le joueur contrôle un vaisseau situé en bas de l'écran. Il peut se déplacer horizontalement et tirer des projectiles afin de détruire une flotte d'aliens.  

Le jeu comprend notamment :  
	- une saisie du nom du joueur ; 
	- le déplacement du vaisseau avec le clavier ; 
	- le tir de projectiles ; le déplacement automatique des aliens ; 
	- la détection des collisions entre les projectiles et les aliens ; 
	- la gestion de la victoire et du Game Over ; 
	- le calcul du score en fonction du temps de jeu ; 
	- l'enregistrement et l'affichage des scores dans un fichier JSON.	
	
	

______________ Environnement de développement:


	- Python : : langage utilisé pour développer le jeu.
	- Tkinter : création de l'interface graphique et gestion des événements clavier.
	- JSON : sauvegarde et chargement des scores.
